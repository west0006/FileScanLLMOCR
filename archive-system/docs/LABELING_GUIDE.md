# 标注规范：档案开放审核训练数据

## 一、OCR 文本标注规范

### 1.1 标注工具
- 推荐：PPOCRLabel（PaddleOCR 官方标注工具）
- 安装：`pip install PPOCRLabel`
- 启动：`PPOCRLabel --lang ch`

### 1.2 标注范围
按以下比例收集各类样本：

| 类型 | 最低数量 | 说明 |
|------|---------|------|
| 1950-1960年代印刷体 | 50 页 | 铅字印刷，字迹可能不均 |
| 1960-1980年代手写体 | 100 页 | 钢笔/毛笔，不同笔迹风格 |
| 1980-2000年代印刷体 | 50 页 | 现代印刷，较清晰 |
| 表格类（名册/统计表） | 80 页 | 含姓名/性别/年龄/籍贯等字段 |
| 印章覆盖 | 30 页 | 红色印章部分覆盖文字区域 |
| 破损/模糊/泛黄 | 40 页 | 纸张老化、水渍、褶皱 |
| 混合排版 | 50 页 | 印刷+手写+表格混合 |

### 1.3 标注内容
每个文本框标注：
- **四点坐标**：左上、右上、右下、左下（顺时针）
- **文本转录**：逐字对照，保留原文文字
- **特殊标记**：
  - `[illegible]` — 确实无法辨认的字符
  - `[seal]` — 印章区域文字（如果能辨认，正常标注）
  - `[table]` — 表格区域（配合 PPStructure 使用）

### 1.4 注意事项
- 繁体字保留原样，不要转换为简体
- 标点符号保留
- 分行/分段保留
- 明显印刷错误不要修正，保留原样
- 每页标注完成后需自检一遍

## 二、LLM 审核标注规范

### 2.1 标注目标
为每条档案产生以下标注信息：

```json
{
  "archive_id": "档案编号",
  "full_text": "档案 OCR 全文",
  "labels": {
    "risk_score": 0-100,
    "risk_level": "低|中|高",
    "sensitive_items": [
      {
        "type": "敏感类型（见下方分类）",
        "content": "敏感内容原文",
        "start_char": 起始字符位置,
        "end_char": 结束字符位置
      }
    ],
    "suggestion": "建议开放|建议部分开放|建议延期开放|建议不予开放",
    "reason": "建议理由（100字以内）"
  }
}
```

### 2.2 敏感类型分类

| 编号 | 类型 | 判定标准 | 示例 |
|------|------|---------|------|
| 1 | 国家秘密 | 标有"绝密""机密""秘密"字样 | "机密★5年" |
| 2 | 未结论事项 | 涉及待调查、审理中的重大问题 | "此案正在审理中" |
| 3 | 内部事项 | 学校内部不对外公开的决策记录 | 校长办公会纪要 |
| 4 | 知识产权 | 专利、版权、商标相关内容 | 专利申请文件 |
| 5 | 个人隐私 | 身份证号、家庭出身、成绩、健康、联系方式 | "家庭出身: 地主" |
| 6 | 上级来文 | 引用国务院、教育部等上级单位文件 | "根据国发[1973]XX号..." |
| 7 | 外收文 | 校外单位来文 | "XX省教育厅函..." |
| 8 | 捐献未授权 | 捐赠档案，权属人未书面同意 | （元数据标记） |
| 9 | 历史敏感内容 | 敏感词库中 400+ 词的真实使用（非客观叙述） | 需结合上下文判断 |

### 2.3 风险评分指南

| 评分区间 | 等级 | 含义 | 判定条件 |
|---------|------|------|---------|
| 0-20 | 低 | 建议开放 | 无任何敏感内容命中；或仅包含已公开的学校基本信息 |
| 21-60 | 中 | 建议人工关注 | 命中 1-5 个敏感类型，但不确定是否构成不开放理由 |
| 61-100 | 高 | 建议延期/不开放 | 明显包含国家秘密、个人隐私等；或命中 >5 个敏感类型 |

### 2.4 特殊判断规则

1. **上下文优先**：敏感词出现不代表一定敏感
   - "学习中央文件精神" → 不敏感（客观叙述）
   - "根据中央XX号机密文件指示" → 敏感（引用涉密文件）

2. **时间因素**：年代久远的档案部分信息可能已脱敏
   - 1970年代的"内部文件"可能已解密，需结合内容判断

3. **已公开信息**：学校简介、领导班子、学科情况等已公开信息 → 建议开放

4. **不确定时**：标注 confidence < 0.7，并注明"需人工复核"

### 2.5 标注流程

```
Step 1: 阅读档案全文（2-3 分钟）
Step 2: 对照敏感词库，标记命中的敏感片段（5-10 分钟）
Step 3: 判断每个命中是否构成真正的不开放理由（2-3 分钟）
Step 4: 综合评分，给出开放建议和理由（2-3 分钟）
Step 5: 自检确认无遗漏（1-2 分钟）

单条标注预计 12-20 分钟
```

### 2.6 质量抽检标准

- 标注完成率 ≥ 95%（不允许遗漏敏感内容）
- 交叉验证一致性 ≥ 85%（两人标注同一份档案，结论一致比例）
- 每 50 条标注抽检 5 条，不一致的返回重标

## 三、数据版本管理

```
train/data/
├── review_raw.json          ← 原始审核记录（L3 内网）
├── review_desensitized.json ← 脱敏后数据（可传到 L2）
├── review_sft.json           ← ShareGPT 格式（LLaMA-Factory 训练用）
├── review_train.json         ← 训练集（70%）
├── review_val.json           ← 验证集（15%）
└── review_test.json          ← 测试集（15%）
```
