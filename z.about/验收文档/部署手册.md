# 部署手册 — 档案智能查询与开放审核系统

## 一、环境要求

| 组件 | 最低要求 | 推荐配置 |
|------|----------|----------|
| 操作系统 | Windows 10+ / Ubuntu 20.04+ / macOS 12+ | Ubuntu 22.04 LTS |
| Python | 3.10+ | 3.11 |
| Node.js | 18+ | 20 LTS |
| 内存 | 8 GB | 16 GB |
| 磁盘 | 5 GB | 20 GB (含模型) |
| GPU（可选） | NVIDIA GTX 1660 6GB+ | NVIDIA RTX 3060 12GB |

## 二、快速启动（Windows PowerShell）

```powershell
cd archive-system

# 1. 一键安装依赖
.\install.ps1

# 2. 一键启动前后端
.\start.ps1

# 3. 浏览器访问
#    前端: http://localhost:3000
#    后端: http://localhost:8000/docs
#    登录: admin / Admin@123456
```

---

## 三、快速启动（Linux / macOS）

```bash
cd archive-system

# 1. 安装 Python 依赖
python3 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt

# 2. 安装前端依赖
cd frontend && npm install && cd ..

# 3. 启动后端 (终端1)
PYTHONPATH=backend python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# 4. 启动前端 (终端2)
cd frontend && npm run dev
```

## 四、Docker 部署

```bash
# 启动全部服务（API + Celery + 前端 + MySQL + ES + Redis）
docker compose up -d --build

# 启动 OCR 服务（可选，需 GPU）
docker compose --profile ocr up -d

# 查看状态
docker compose ps

# 访问
# 前端: http://localhost:3000
# API:  http://localhost:8000/docs
```

## 六、环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `APP_ENV` | development | development / production |
| `LLM_MODE` | mock | mock / ollama / real（ollama需本地Ollama；real需LLaMA-Factory） |
| `OCR_MODE` | mock | mock / real（real需PaddleOCR） |
| `DB_MODE` | sqlite | sqlite / mysql |
| `DB_PASSWORD` | — | MySQL 密码（mysql模式必填） |
| `JWT_SECRET` | — | 生产环境务必修改 |
| `ES_HOST` | elasticsearch | ES 地址（Docker 内为 elasticsearch） |
| `REDIS_HOST` | redis | Redis 地址 |
| `OLLAMA_URL` | http://localhost:11434 | Ollama 服务地址（LLM_MODE=ollama 时） |
| `OLLAMA_MODEL` | qwen2.5:3b | Ollama 模型名 |

## 七、开发模式 vs 生产模式

| 特性 | 开发模式 | 生产模式 |
|------|----------|----------|
| 用户创建 | 自动创建 (reviewer) | 管理员手动创建 |
| 密码校验 | 不校验 | 严格校验+锁定+过期 |
| 数据库 | SQLite | MySQL 8.0 |
| 全文搜索 | SQLite LIKE | ES + IK 分词 |
| Celery | memory:// 同步 | Redis + 异步 Worker |
| LLM | mock | LLaMA-Factory API |
| OCR | mock | PaddleOCR GPU/CPU |

切换方式：修改 `.env` 中 `APP_ENV=production`，配置 MySQL/ES/Redis 连接。

## 八、故障排查

| 现象 | 原因 | 解决 |
|------|------|------|
| 前端 401 | Token 过期 | 重新登录 |
| 搜索返回空 | ES 不可用 (Docker 未启动) | `docker compose up -d elasticsearch` 或使用 SQLite 降级 |
| OCR 任务卡住 | Redis 不可用 | 开发模式自动降级，生产环境 `docker compose up -d redis` |
| 端口占用 | 8000/3000 被占用 | 修改 vite.config.ts 和启动参数 |
| npm install 失败 | Node 版本过低 | 升级到 Node 18+ |
