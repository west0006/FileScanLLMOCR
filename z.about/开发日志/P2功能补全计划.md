# P2 功能补全计划（需求 vs 实现差距）

> 日期：2026-08-XX
> 范围：验收 bug list 中「需求文档要求、前端实现简化/缺失」的功能项
> 方法：同 P0/P1——分批次实现，每批审查前后端契约，再进入下一批

## 批次划分

| 批次 | 模块 | 内容 | 复杂度 |
| --- | --- | --- | --- |
| P2-1 | 检索 | 文件编号维度、结果筛选标签栏 | 低（前后端各加项） |
| P2-2 | 检索 | 目录树二级部门节点 + 部门过滤后端支持 | 中（需拆 category/department） |
| P2-3 | 检索 | 归档年度范围/多选、多字段独立输入框 | 中（UI 重构） |
| P2-4 | OCR | 创建任务弹窗目录树/全选清空、优先级调整入口、详情字段补全 | 中 |
| P2-5 | 预审 | 日期选择器、新建任务弹窗补批次/目录树/截止日期、任务表头全选 | 中 |
| P2-6 | 用户/角色 | 锁定按钮、查档人员角色、角色目录树授权、内置角色保护 | 中-高 |
| P2-7 | 日志/统计 | 四张统计卡、操作三分类、target_id 覆盖、审计说明 | 中 |
| P2-8 | 在线用户 | 强制下线、IP/会话时长/位置/当前操作真实化 | 高（需后端会话状态） |

## 备注

- 「多字段独立输入框」「年份范围多选」等属于交互重构，需先与需求文档逐项对齐字段语义，避免误做。
- P2-8 在线用户真实会话状态依赖后端维护 token→活动映射（当前是内存字典 + 估算），建议单独评估。
- 每批完成后按「前后端契约 / 参数传递 / 错误分支 / 权限消费 / 回归」五项审查。
