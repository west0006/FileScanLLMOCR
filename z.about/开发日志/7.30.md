## 三、关键修复详解

### 3.1 导出全链路修复（Bug #6）

**修改前链路（断裂）**：
```
前端: searchApi.export({ archive_ids: [...] })
  → POST /api/search/export  Body: {"archive_ids":["..."]}
  → 后端: def export_results(format: str, archive_ids: list[str])  ← 从 query string 读，body 被忽略
  → archive_ids = [] → 导出全部而非筛选结果
  → return {"status":"ok", "file":"xxx.xlsx"}  ← JSON，无文件下载
  → 前端: ElMessage.success(...)  ← 只弹 toast，浏览器无下载
```

**修改后链路（完整）**：
```
前端: searchApi.export({ archive_ids: [...] })
  → POST /api/search/export  Body: {"archive_ids":["..."]}
  → 后端: def export_results(req: ExportRequest)  ← Pydantic 模型解析 body
  → 正确过滤 → export_to_excel → FileResponse(Content-Disposition: attachment)
  → 前端: responseType:'blob' → createObjectURL → <a>.click() → 浏览器下载
```

### 3.2 关联档案导航修复（Bug #2 + #3）

三层修复：
1. **可点击性**：`<router-link>` → `<a>` + `@click.prevent` + `router.push`，CSS 显式 `cursor: pointer`
2. **同组件刷新**：提取 `loadDetail(id)` + `watch(route.params.id, ...)`，param 变化时自动重载
3. **竞态保护**：`loadSeq` 请求序号计数器，每次 `await` 后校验 `seq !== loadSeq` 丢弃过期响应；开始前清空全部 ref 防 UI 残留

### 3.3 目录树检索修复（Bug #10）

**根因**：`scopeTreeData` 节点 ID 为虚构值 `cat-admin`/`admin-2025`，后端 `_build_level_filter` 将其作为 `category` 值传入 ES/SQLite：
```sql
WHERE category IN ('admin-2025')  -- 0 条匹配
```

**修复**：将树数据改为扁平列表，ID 直接使用 DB 中的门类名称（`行政档案`/`党群档案`/...），移除无对应过滤机制的年度/部门子节点。
