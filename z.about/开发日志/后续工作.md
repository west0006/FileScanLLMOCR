### 1. 启动系统验证

```powershell
cd archive-system
.\install.ps1
.\start.ps1
# 浏览器打开 http://localhost:3000
# 登录 admin / 任意密码
```

走一遍核心流程：检索 → 点结果 → 送审 → 工作台预审 → 查看预审记录。确认 76 项功能都能跑。

---

### 2. 部署 PaddleOCR 真机推理（有 GPU 的机器上）

```powershell
.\install.ps1 -WithOCR          # 自动检测 GPU/CUDA → 装 PaddleOCR
$env:OCR_MODE = "real"          # 切换到真实模式
.\start.ps1                     # 重启
```

然后用 OCR 任务管理页面创建一个任务，看是否能真实识别图像。如果没 GPU 就跳过，mock 模式也能演示。

---

### 3. 启动 ES 全文检索（需要 Docker）

```bash
docker compose up -d elasticsearch   # 先启 ES
bash backend/scripts/init_es.sh      # 创建索引
docker compose up -d                 # 全量启动
```

然后对比关键词检索的性能变化（SQLite vs ES）。

---

### 4. LoRA 微调（需要向日葵连学校主机）

1. 向日葵 → 学校主机 (10.11.10.32) → 浏览器 → `http://10.11.13.100:7860`
2. 上传 `train/data/review_sft.json`
3. 在 Web UI 注册数据集 `archive_review`
4. 用 `train/llm/configs/lora_train.yaml` 跑 QLoRA 训练（3B 模型，6GB 显存够）
5. 导出模型 → 改 `.env` 的 `LLM_MODE=real`

---

### 5. 生产环境切换

改 `.env`：

```
APP_ENV=production
DB_MODE=mysql
DB_PASSWORD=你的密码
JWT_SECRET=随机字符串
```

生产模式会自动启用：密码校验 + 5次锁定 + 30天过期 + 权限强制消费。
