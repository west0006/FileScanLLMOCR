## 一、知识图谱 / SE-009 关联检索

### 实体抽取引擎
- 新增 `services/entity_extractor.py`（160行）：6类中文实体
  - 👤 人名（Top 100 姓氏 + 1-3字名）
  - 🏛️ 机构（大学/学院/处/部/室等后缀 + 校内部门词典）
  - 📅 日期（`1996年`/`一九九六年`/`1996.01.01`）
  - 📄 文件编号（`校党字[1995]第12号`/`国务院[1973]...`）
  - 📌 事件（12类：招生/毕业/人事任免/会议/财务/处分/审计/历史运动等）
  - 📍 地名（省/市/区/县）
- Archive 模型新增 `entities` JSON 字段，首次访问自动抽取并缓存

### 知识图谱 API
- `GET /archives/{id}/knowledge-graph`：基于实体共现的关联网络
  - 返回 nodes（档案节点 + 实体节点）+ edges（has_entity + shared_entity）
  - 实体摘要 + 关联档案计数
- ArchiveDetail 左侧新增「🧠 知识图谱」卡片：按类型分组展示标签

### 测试
- `test_knowledge_graph.py`（12个用例）：空文本/人名/机构/日期/文件编号/事件/位置精确/汇总去重/共享实体/真实OCR文本/端点200/不存在返回空
